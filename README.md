# Rifay Umami

Книга с рецепти — уеб приложение (PWA), което се инсталира на iPhone от Safari → Сподели → „Добави към началния екран“.

Сайт: https://rifayumami.online

## Структура

| Файл | Какво е |
| --- | --- |
| `index.html` | Обвивката на приложението |
| `app.js` | Логика на приложението (търсене, категории, редактор, настройки, локални данни) |
| `cloud.js` | Акаунти и споделени рецепти (Supabase) — виж `SETUP.md` |
| `config.js` | Ключове за Supabase (празен = само локално) |
| `supabase/schema.sql` | Таблици и правила за достъп за базата |
| `styles.css` | Дизайн, светла/тъмна тема |
| `sw.js` | Офлайн режим (service worker) |
| `recipes.json` | Оригиналните рецепти от PDF файловете |
| `img/` | Снимките към рецептите |
| `icons/` | Иконата на приложението |

## Как се обновява

Всяка промяна, качена в `main`, се публикува автоматично от GitHub Pages (Settings → Pages). Старият Netlify сайт остава със стара версия.

Ако се промени `recipes.json`, вдигни `SEED_VERSION` в `app.js` — тогава инсталираните приложения обновяват оригиналните рецепти (запазват любими, „изпробвана“, собствени снимки и редактираните от потребителя рецепти).

## Локален тест

```bash
python -m http.server 8000
```

После отвори http://localhost:8000
